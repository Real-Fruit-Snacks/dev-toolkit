#   Id              latest stable version
#   Id 1.2.3        exactly that version (it also replaces the version taken from the top list)
#   Id 1.2.*        latest stable version starting with 1.2.
#   !Pattern        drop matching ids from the top list (* and ? are wildcards). Ids listed on their
#                   own line above still go in. The comment after the pattern is the recorded reason.
#
# Text after # is a comment.
